# Imágenes de ejercicios

Pon aquí las imágenes que referencias en `routine.js` (por ejemplo `biceps.jpg`).

- Formato: JPG o PNG. Ideal ~800×600 px (proporción 4:3).
- El nombre del archivo debe coincidir exactamente con el `image` del ejercicio.
- **No pasa nada si falta una imagen**: la app muestra solo el nombre y las repeticiones,
  sin romperse. Puedes ir añadiéndolas poco a poco.
